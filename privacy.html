개인정보처리방침 (Privacy Policy)

시행일: 2026년 10월 10일

1. 사용 목적

스토리월드 업로더(이하 "이 앱")는 채널 운영자 본인이 Google OAuth로 로그인해, 본인이 만든 영상을 본인의 유튜브 채널에 업로드하고, 제목·설명·예약 공개 시각을 설정하고, 업로드 처리 상태를 확인하는 데에만 사용됩니다.

2. 접근하는 데이터

이 앱은 YouTube Data API 권한(youtube.upload, youtube)을 사용해 운영자 본인 채널의 동영상 업로드·수정·조회만 수행합니다. 다른 사용자의 데이터에는 접근하지 않습니다.

3. 저장과 공유

로그인 토큰은 운영자 본인의 컴퓨터에만 저장되며, 외부 서버로 전송하거나 제3자와 공유하지 않습니다. 이 앱은 개인정보를 수집·판매·광고에 이용하지 않습니다.

4. 권한 철회

Google 계정의 보안 설정(https://myaccount.google.com/permissions)에서 언제든지 이 앱의 접근 권한을 철회할 수 있습니다.

이 앱의 YouTube API 사용은 YouTube API 서비스 약관과 Google 개인정보처리방침을 따릅니다.

English summary

This app is used only by the channel owner to upload and schedule the owner's own videos via the YouTube Data API. OAuth tokens are stored only on the owner's computer and are never shared with third parties. No personal data is collected, sold, or used for advertising. Access can be revoked at any time at https://myaccount.google.com/permissions. Use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.
